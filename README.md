# BNK 부산은행 홈페이지 UI

BNK 부산은행을 콘셉트로 제작한 **정적 웹페이지 UI 프로젝트**입니다.  
HTML과 CSS를 기반으로 은행 홈페이지에서 자주 사용하는 메뉴와 콘텐츠를 하나의 페이지에 구성했으며, PC·태블릿·모바일 환경을 고려한 반응형 레이아웃을 적용했습니다.

> 본 프로젝트는 실제 금융 서비스가 아닌 **웹페이지 UI 구현 및 반응형 웹 연습을 위한 프로젝트**입니다.

---

## 📌 프로젝트 개요

은행 홈페이지의 기본적인 구조를 참고하여 다음과 같은 화면을 구현했습니다.

- 상단 유틸리티 메뉴
- 메인 네비게이션
- 메인 배너
- 금융 서비스 바로가기
- 새소식
- 이벤트
- 빠른 로그인
- 빠른서비스
- 추천 금융상품

페이지의 HTML 구조와 CSS 스타일은 `index.html` 파일 하나에 작성되어 있습니다.

---

## 🛠 사용 기술

| 기술 | 용도 |
|---|---|
| HTML5 | 웹페이지 구조 및 콘텐츠 구성 |
| CSS3 | 디자인 및 레이아웃 구현 |
| Flexbox | 메뉴와 카드형 콘텐츠 배치 |
| Media Query | 화면 크기에 따른 반응형 처리 |

JavaScript나 별도의 프레임워크는 사용하지 않았습니다.

---

## 📂 프로젝트 구조

```text
.
└── index.html
```

`index.html` 내부에 HTML과 CSS가 함께 작성되어 있어 별도의 스타일시트 파일 없이 바로 실행할 수 있습니다.

---

## 🖥 화면 구성

### 1. Header

페이지 상단에 은행 홈페이지에서 사용하는 기본 메뉴를 구성했습니다.

**상단 메뉴**
- 개인뱅킹
- 기업뱅킹
- 금융상품
- 로그인
- 인증센터
- 은행소개
- Global

**메인 네비게이션**
- 개인뱅킹
- 기업뱅킹
- 금융상품
- 카드
- 서비스

오른쪽에는 검색 및 전체 메뉴 버튼 UI를 배치했습니다.

---

### 2. Main Banner

메인 영역에는 다음과 같은 메시지를 배치했습니다.

> **당신의 금융생활을 더 편리하게**

현재 이미지가 들어갈 영역은 `MAIN BANNER`라는 플레이스홀더 형태로 구성되어 있습니다.

---

### 3. 금융 서비스 바로가기

사용자가 자주 이용하는 서비스를 빠르게 접근할 수 있도록 6개의 메뉴를 배치했습니다.

- 💰 계좌조회
- ↔ 이체
- 💳 카드
- 📄 증명서발급
- 🏦 영업점 찾기
- ☎ 고객센터

각 항목에는 마우스를 올렸을 때 테두리와 글자 색상이 변경되는 Hover 효과를 적용했습니다.

---

### 4. 새소식

은행 관련 공지사항을 목록 형태로 표시했습니다.

예시 내용:
- 부산은행 새로운 금융서비스를 안내드립니다.
- 인터넷뱅킹 서비스 이용 안내
- 금융상품 변경사항 안내
- 시스템 점검 일정 안내

각 항목에는 제목과 날짜를 함께 표시합니다.

---

### 5. 이벤트

이벤트 콘텐츠를 카드 형태로 구성했습니다.

- **Welcome Event**
  - 새로운 고객을 위한 특별한 혜택
- **Digital Banking**
  - 모바일 금융서비스 이벤트

---

### 6. 빠른 로그인

오른쪽 영역에 개인 고객과 기업 고객을 구분한 로그인 버튼을 배치했습니다.

- 개인
- 기업

현재는 화면 디자인만 구현되어 있으며 실제 로그인 기능은 연결되어 있지 않습니다.

---

### 7. 빠른서비스

주요 금융 서비스를 별도의 목록으로 구성했습니다.

- 환율조회
- 금리조회
- 영업점 찾기
- ATM 찾기
- 고객센터

---

### 8. 추천 금융상품

예금·적금·대출·카드 상품을 카드 형태로 배치했습니다.

| 구분 | 상품명 | 표시 내용 |
|---|---|---|
| 예금 | BNK 주거래 우대통장 | 최고 3.20% |
| 적금 | BNK 행복적금 | 최고 4.10% |
| 대출 | BNK 신용대출 | 최저 4.50% |
| 카드 | BNK 생활카드 | 다양한 혜택 |

※ 위 상품명과 금리는 **페이지 UI 구성을 위한 예시 데이터**입니다.

---

## 📱 반응형 웹

화면 너비에 따라 콘텐츠 배치가 변경되도록 CSS Media Query를 사용했습니다.

### PC 화면

- 콘텐츠 최대 너비 1200px
- 좌우 2단 콘텐츠 구성
- 금융상품 카드 가로 배치

### 900px 이하

- 주요 콘텐츠를 세로 방향으로 변경
- 금융상품을 2열 형태로 배치

### 600px 이하

- 상단 유틸리티 메뉴 숨김
- 메인 네비게이션 숨김
- 메인 배너 세로 배치
- 바로가기 메뉴 2열 배치
- 이벤트 카드 세로 배치
- 금융상품 카드 1열 배치

## ▶ 실행 방법

별도의 설치나 빌드 과정이 필요하지 않습니다.

### 방법 1. 파일 직접 실행

`index.html`을 웹 브라우저로 열면 바로 확인할 수 있습니다.

VS Code에서 Live Server 등의 로컬 웹 서버를 사용하여 실행할 수 있습니다.

```text
index.html
```

## ⚠️ 참고사항

이 프로젝트는 **정적 UI 페이지**이므로 실제 금융 서비스 기능은 구현되어 있지 않습니다.

현재 구현되지 않은 기능:

- 로그인
- 계좌조회
- 이체
- 카드 조회 및 관리
- 금융상품 실제 조회
- 환율 및 금리 데이터 연동
- 영업점 및 ATM 검색
- 게시판 상세 페이지
- 이벤트 상세 페이지

또한 홈페이지에 표시된 공지사항, 이벤트, 금융상품 및 금리 정보는 실제 서비스 데이터가 아닌 **UI 테스트용 예시 콘텐츠**입니다.
