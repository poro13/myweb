class 속성 관리

classList는 HTML 요소의 CSS 클래스를 추가,삭제,확인,전환할 때 사용한다.

메소드 설명 예시
add() 클래스 추가 e1.classList.add('active')
remove() 클래스 삭제 e1.classList.remove('active')
toggle() 있으면 클래스 삭제, 없으면 추가 e1.classList.toggle('active')
contains() 클래스 존재 여부 확인 e1.classList.contains('active')
replace() 기존 클래스를 다른 클래스로 변경 e1.classList.replace('old','new')
