1. 기본 집계 함수

SQL의 집계 함수는 여러 행의 데이터를 하나의 값으로 계산할 때 사용한다. 대표적인 집계 함수는 COUNT(), SUM(), AVG(), MAX(), MIN()이 있다.

  • COUNT() : 데이터의 개수를 구한다.
  • SUM() : 숫자 데이터의 합계를 구한다.
  • AVG() : 숫자 데이터의 평균을 구한다.
  • MAX() : 가장 큰 값을 구한다.
  • MIN() : 가장 작은 값을 구한다.

집계 함수는 전체 데이터를 대상으로 사용할 수도 있고, GROUP BY와 함께 사용하여 부서별, 직급별, 지역별로 데이터를 묶어서 계산할 수도 있다.

기본 형식

                    SELECT 그룹컬럼, 집계함수(컬럼)
                    FROM 테이블명
                    GROUP BY 그룹컬럼;
