Having 절

HAVING 절은 GROUP BY로 만들어진 그룹에 조건을 지정할 때 사용한다.
일반적인 WHERE절은 그룹화 하기 전에 개별 행에 조건을 적용하지만, HAVING 절은 그룹화가 끝난 후
집계 결과에 조건을 적용한다.
예를 들어 부서별 평균 급여를 계산한 뒤, 평균 급여가 일정 금액 이상인 부서만 출력하고 싶을 때 HAVING절을 사용한다.
기본 형식은 다음과 같다.

기본 형식

                SELECT 그룹컬럼, 집계함수(컬럼)
                FROM 테이블명
                GROUP BY 그룹컬럼
                HAVING 집계함수(컬럼) 조건;

문제2

emp3 테이블에서 부서별 평균 급여를 출력하되, 평균 급어가 4,000,000원 이상인 부서만 출력하는 SQL문이다.
빈칸에 들어갈 식을 고르시오.

문제 쿼리

SELECT dept,
        ROUND(AVG(salary)) AS 평균급여
FROM emp3
GROUP BY dept
HAVING AVG(salary) >= 4000000;
